About

Focused on the unglamorous parts that actually matter.

Most of my work lives in the space between "it works on my machine" and "someone who isn't a developer needs to use this today." That means form validation, state that doesn't get lost, and interfaces that hold up when the input is messy.

Recent work has centered on WhiteRock Connect, a React Native / Expo app, alongside a set of structured intake tools — UK visa application forms and interview-prep sites — built to turn a stressful paper process into something a person can finish in one sitting.

Profile bio says it plainly: 🎯 Focusing. One thing at a time, built properly.
